# Scratch Sensei V1 is a native Mixxx feature

Status: accepted

Scratch Sensei V1 should be implemented as a native Mixxx feature, not as a separate app or external companion tool.

## Consequences

- Implementation planning starts from the V1 spec and linked ADRs.
- The feature should use Mixxx-native analysis, library, deck, and cue APIs.
- Scope decisions belong in the V1 spec before code is written.
