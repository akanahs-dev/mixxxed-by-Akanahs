This is a proposed starter curriculum for Scratch Sensei practice. It narrows the full DJ skill reference to skills that Scratch Sensei can plausibly teach with track structure, cue markers, energy/tension views, compatibility hints, and simple tutor prompts.

---

## Selection Rule

Include skills when Scratch Sensei can help the learner see or rehearse the decision:

- track structure, phrase, section, drop, breakdown, or cue timing
- energy, tension, vocal density, bass density, or frequency management
- transition choice, transition timing, or mistake recovery
- simple visual explanation that can fit inside the Tutor panel

Defer skills when they need hardware-specific performance, advanced stems, deep crowd context, or long set planning.

## Tier 1 - Foundation Skills

These should be the first lessons because they make every later transition easier to understand.

| Skill | Why Scratch Sensei can teach it | Suggested lesson prompt |
| --- | --- | --- |
| Beat identification | Beat lanes and waveform markers can show the pulse. | Find the next beat and tap along for 16 beats. |
| Downbeat identification | Section changes and phrase markers can show beat one. | Mark where the next phrase starts. |
| Bar counting | Bar/phrase lanes can show groups of four beats. | Count four bars before the next section. |
| Phrase counting | Scratch Sensei already depends on phrases and sections. | Predict the next 8-bar or 16-bar change. |
| Section identification | Structure Markers can label intro, build, drop, breakdown, and outro. | Choose whether the current section is safe for entry, exit, or waiting. |
| Structural previewing | The learner can see upcoming changes before they arrive. | Use the timeline to name the next important moment. |

## Tier 2 - Track Preparation Skills

These make Scratch Sensei useful before performance.

| Skill | Why Scratch Sensei can teach it | Suggested lesson prompt |
| --- | --- | --- |
| Beat-grid preparation | Incorrect grids break phrase, cue, and loop guidance. | Check whether the grid lands on downbeats. |
| Cue-point placement | Structure Markers can become learner-visible cue suggestions. | Place an entry cue at a clean phrase start. |
| Memory cue placement | Warnings before vocals, drops, or exits reduce panic. | Add a reminder one phrase before the drop. |
| Loop preparation | Loops support intro extension and recovery. | Save a safe 8-bar loop before the outro. |
| Energy mapping | Energy lanes can show high, low, build, and release sections. | Label which section raises or lowers energy. |
| Vocal-density mapping | Vocal lanes prevent vocal-on-vocal mistakes. | Mark where the vocal begins and ends. |
| Bass-density mapping | Bass lanes help teach clean low-end swaps. | Identify where the incoming bass should take over. |
| Tension mapping | Builds and releases explain expectation. | Mark the build, hold, and release. |
| Mix-in suitability | The tutor can ask whether a section has room for another track. | Choose the cleanest entry point. |
| Mix-out suitability | The tutor can show when leaving will damage or preserve arrangement. | Choose the safest exit section. |

## Tier 3 - Timing And Phrase Transition Skills

These are the most natural Scratch Sensei practice targets.

| Skill | Why Scratch Sensei can teach it | Suggested lesson prompt |
| --- | --- | --- |
| Tempo matching | BPM and beat lanes expose whether tracks can stay aligned. | Match the incoming track tempo before launch. |
| Phase matching | Beat lanes can show kicks drifting or flamming. | Nudge until the beats align. |
| Downbeat matching | Phrase lanes can show whether beat one lines up. | Start Deck B on the same bar position as Deck A. |
| Sync-assisted matching | The lesson can separate sync from musical judgement. | Use sync, then choose the correct phrase start manually. |
| Phrase alignment | This is core to Scratch Sensei section-aware practice. | Launch the incoming phrase at the matching outgoing phrase. |
| Section alignment | Structure Markers can compare intro, build, drop, breakdown, and outro. | Match an outgoing outro to an incoming intro. |
| Drop swap | Drops are explicit Structure Markers. | Replace the expected drop with another track's drop. |
| Build-to-drop transition | Tension and section lanes can show build into release. | Use Track A build to land Track B drop. |
| Breakdown-to-drop transition | Breakdown and drop markers make the contrast visible. | Redirect the breakdown into a new drop. |
| Section contrast | The tutor can ask why a high-energy section should move into space. | Move from a drop to a breakdown without sounding accidental. |

## Tier 4 - EQ, Filter, And Frequency Skills

These require control movement, but Scratch Sensei can show the reason and timing.

| Skill | Why Scratch Sensei can teach it | Suggested lesson prompt |
| --- | --- | --- |
| Three-band EQ blending | Frequency lanes can show low, mid, and high conflicts. | Remove the outgoing lows before the incoming bass enters. |
| Bass swap | Bass density and phrase markers define the swap moment. | Swap basslines on the downbeat of the next phrase. |
| Gradual bass handoff | The timeline can show a multi-bar handoff window. | Fade lows across 8 bars without stacking sub bass. |
| Midrange handoff | Vocal and melody density can warn about masking. | Clear space for the incoming hook. |
| High-frequency handoff | Percussion brightness can be shown in a frequency lane. | Move hats and brightness from Deck A to Deck B. |
| Vocal carving | Vocal density makes midrange conflict visible. | Reduce the competing midrange under a vocal. |
| High-pass transition | The learner can see why bass is removed before entry. | High-pass the incoming track until its bass should arrive. |
| Low-pass transition | Useful for smooth exits and energy reduction. | Low-pass the outgoing track through the next phrase. |
| Filter reveal | Teaches anticipation without full dominance. | Reveal the incoming track over 8 bars. |
| Filter reset drop | Drop markers provide the reset timing. | Release the filter exactly at the drop. |

## Tier 5 - Loop, Cue, And Recovery Skills

These turn Scratch Sensei from a visualizer into a practice coach.

| Skill | Why Scratch Sensei can teach it | Suggested lesson prompt |
| --- | --- | --- |
| Emergency loop | The tutor can detect an approaching unsafe ending. | Loop a safe section before the track exits. |
| Intro extension loop | Structure Markers show when more blend time is needed. | Extend the intro until Deck A reaches its outro. |
| Outro extension loop | Helps make a safe exit window. | Loop the outgoing groove for one more phrase. |
| Loop exit on phrase | Prevents random loop release. | Exit the loop on the next phrase boundary. |
| Instant section launch | Structure Markers become navigable practice targets. | Jump to the next drop cleanly. |
| Drop jumping | Drop markers can become exact jump targets. | Jump from the current phrase to the next drop. |
| Breakdown jumping | Breakdown markers create controlled energy reset. | Jump into space without breaking phrase timing. |
| Cue-based phrase repair | The tutor can show the correct structural position after a miss. | Repair a late launch using the nearest phrase cue. |
| Cue-based clean edit | Section skipping supports flexible arrangement. | Skip the unsuitable section and rejoin on phrase. |
| Wrong-phrase recovery | A mistake simulation can show the error and repair. | Fix an off-phrase transition without stopping. |
| Unexpected-vocal recovery | Vocal lanes can show a collision. | Clear or exit when an unmarked vocal appears. |
| Unexpected-breakdown recovery | Energy lanes can show an unplanned energy drop. | Loop the previous groove or bring in a rhythm layer. |
| Missed-drop recovery | Drop markers let the learner recover without panic. | Wait for the next valid drop or cue to it cleanly. |
| Safe exit | Teaches ending a bad transition early. | Choose the least damaging exit when the blend deteriorates. |

## Tier 6 - Compatibility And Decision Skills

These make Scratch Sensei feel like a tutor instead of a checklist.

| Skill | Why Scratch Sensei can teach it | Suggested lesson prompt |
| --- | --- | --- |
| Same-key mixing | Harmony lane can explain stable blends. | Pick the most harmonically stable transition candidate. |
| Adjacent-key mixing | Useful once same-key is understood. | Choose a compatible but more energetic key move. |
| Section-specific harmonic mixing | Keyless or sparse sections can make difficult tracks mixable. | Find a section where harmony matters less. |
| Vocal avoidance | Vocal lane makes overlap risk visible. | Avoid two lead vocals colliding. |
| Vocal handoff | Can be shown as one vocal ending while another begins. | Time the incoming vocal after the outgoing vocal phrase. |
| Energy matching | Energy lanes can score compatible sections. | Pick a section with similar energy. |
| Energy lifting | Teaches controlled rise. | Move to a higher-energy section without jumping too early. |
| Energy reducing | Teaches release and recovery. | Exit from peak into space deliberately. |
| Transition suitability selection | Pulls structure, harmony, vocals, and energy together. | Choose the best transition type for this track pair. |
| Complexity matching | Helps prevent over-layering dense material. | Choose simple or layered mixing based on section density. |
| Risk assessment | Encourages safer choices before performance. | Decide whether the double drop is worth attempting. |
| Musical-priority selection | Teaches what to preserve: rhythm, harmony, vocal, energy, or narrative. | Name the one thing this transition must protect. |
| Transition-window selection | Helps choose the best moment, not just the next moment. | Pick the strongest available transition window. |
| Restraint | Prevents unnecessary effects and layering. | Choose the simplest technique that solves the musical problem. |

## Tier 7 - Visualizer Modes To Support The Curriculum

These visual modes directly support the proposed lessons.

| Visual mode | Use in Scratch Sensei |
| --- | --- |
| Beat lane | Timing, phase, nudging, and beat identification. |
| Bar and phrase lane | Phrase counting, downbeat matching, and phrase repair. |
| Section lane | Entry, exit, drop, breakdown, and structural preview. |
| Energy lane | Energy matching, lifting, reducing, and peak/release decisions. |
| Frequency lane | EQ blending, bass swaps, and frequency conflicts. |
| Harmony lane | Harmonic mixing and section-specific key decisions. |
| Vocal lane | Vocal avoidance, vocal handoff, and unexpected-vocal recovery. |
| Bass lane | Bass swap and sub-bass protection lessons. |
| Tension lane | Build-to-drop and expectation-management lessons. |
| Transition overlay | Step-by-step timing for control movement. |
| Decision explanation panel | Explains why a technique fits the current track pair. |
| Alternative transition comparison | Shows more than one valid solution. |
| Mistake simulation mode | Contrasts correct timing with phrase, bass, and vocal errors. |
| Step-sequence mode | Breaks a transition into practiceable actions. |
| Practice mode | Hides later steps until the learner chooses the next move. |

## Defer For Later

These are valuable DJ skills, but they should not be first-pass Scratch Sensei lessons.

| Skill area | Why defer |
| --- | --- |
| Full scratching and turntablism | Needs hardware feel, fader technique, and expressive timing beyond structure analysis. |
| Advanced stem performance | Depends on stem quality, routing, and artifact handling. |
| Crowd-reading and venue adaptation | Needs live audience feedback that Scratch Sensei cannot infer from tracks alone. |
| Full set construction | Better after individual transition skills are reliable. |
| Multi-deck live remixing | High complexity and too many simultaneous decisions for the first tutor flow. |
| Effects-heavy performance | Easy to over-teach before structure, phrase, and EQ basics are stable. |
